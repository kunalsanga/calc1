# Professional Calculator

A sophisticated and responsive calculator application built with HTML, CSS, and JavaScript. This calculator features standard arithmetic operations, memory functions, history tracking, and a clean, modern interface.

## Features

- **Basic Operations**: Addition (+), Subtraction (-), Multiplication (×), Division (/), and Percentage (%)
- **Memory Functions**: Memory recall (MR), memory add (+), memory subtract (-), and memory clear (MC)
- **History Tracking**: View recent calculations and toggle full history view
- **Keyboard Support**: Navigate the calculator using keyboard shortcuts
- **Responsive Design**: Works seamlessly across desktop and mobile devices
- **Enhanced Display**: Shows recent calculations and provides visual feedback

## Interface

The calculator features a professional dark-themed interface with:
- Large, readable display showing current calculations
- Intuitive button layout following standard calculator conventions
- Memory and history controls for advanced operations
- Smooth animations and visual feedback on interactions

## Usage

1. **Basic Calculations**: Click numbers and operators to perform calculations
2. **Memory**: Use memory buttons to store and recall values
3. **History**: Click the calendar icon to view calculation history
4. **Keyboard**: Use keyboard for faster operation (numbers, operators, Enter for calculate, Esc for clear)

## Technical Details

- **HTML5**: Semantic markup for structure
- **CSS3**: Modern styling with gradient backgrounds and animations
- **JavaScript**: Core calculator logic with safe evaluation
- **Responsive**: Grid-based layout for mobile compatibility

## Project Structure

- `index.html`: Main calculator interface
- `styles.css`: Styling and responsive design
- `script.js`: Calculator logic and functionality
